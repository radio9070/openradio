# OPEN RADIO - Web Player

Reproductor web moderno, interactivo y totalmente adaptable (*responsive*) para la transmisión en directo de **OPEN RADIO**. Construido con HTML5, CSS3 y JavaScript nativo, optimizado para ejecutarse en GitHub Pages de forma rápida y sin dependencias externas pesadas.

---

## 📻 Características

* **Transmisión en directo continua:** Conectado directamente al streaming oficial de ZenoFM en alta disponibilidad.
* **Diseño Responsive:** Totalmente adaptado para teléfonos inteligentes, tablets y computadoras de escritorio.
* **Efectos visuales fluidos:** Fondo desenfocado dinámico con arte de fondo y disco central giratorio con la identidad de la radio.
* **Control interactivo de audio:** Botón dinámico de reproducción/pausa y barra deslizadora para regular el volumen en tiempo real.
* **Integración con MediaSession API:** Permite controlar la reproducción y ver los datos de la emisora desde la barra de notificaciones o la pantalla de bloqueo de cualquier dispositivo.
* **Accesos directos a Redes Sociales:** Botones flotantes integrados para conectar directamente con Facebook e Instagram oficiales.
